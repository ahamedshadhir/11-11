# 11-11 change practice

Every product change must land in all three places:

1. **GitHub** — https://github.com/ahamedshadhir/11-11
2. **Vercel** — https://elevenelven.vercel.app (auto from main)
3. **Figma** — https://www.figma.com/design/qCUL32YZLJq3m2JvFMpTCT

## Figma pages
- 00 Cover — brand
- 01 Desktop — Home, Shop, Login, Register, Cart (live captures)
- 03 Mobile — Mobile Home, Mobile Login, Mobile Checkout
- 05 Journeys — numbered user flows

After a UI change: push code, wait for Vercel Ready, recapture the changed screen into the matching Figma frame.
